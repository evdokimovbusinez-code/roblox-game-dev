# Roblox game-dev skill

**English summary.** A Claude skill that acts as a turnkey Roblox game developer and a visionary advisor in one. It works in two modes: (A) audit and improve an existing game, (B) create a game from scratch, always following a "big to small" principle (whole game, then structure, then greybox, then systems, then style, then polish). It bundles a Rojo/Luau project template with a code-only UI library, a Studio place scanner, Open Cloud automation, and about 40 reference files (genres, mechanics atlas, monetization, discovery, packaging, level design, 3D/animation/audio pipelines, AI art workflow, compliance, live-ops). The content is written in Russian; data is current as of October 2026. No license is specified: all rights reserved by the author.

## Что это

Скилл для Claude, который работает как **разработчик Roblox-игр под ключ** и одновременно как **советник-визионер**. Builder делает: дизайн-документ, проект, код на Luau, системы, UI, монетизацию, настройки, упаковку и план лайв-опса. Advisor на каждом важном решении даёт рекомендацию, объясняет почему (кейсы, цифры, сигналы алгоритма), называет риски и честно говорит, когда идея слабая или нарушает правила.

### Два режима

- **A. Оценка и доработка готовой игры.** Intake, аудит сверху вниз, отчёт с оценками, план доработки от крупного к мелкому, исполнение и проверка.
- **B. Создание с нуля.** Конвейер из этапов 0-9: от идеи и вердикта советника до опубликованной, монетизированной и живущей игры.

### Принцип «от крупного к мелкому»

Игра целиком, затем структура, затем грейбокс карты и экранов, затем функциональность систем, затем единый стиль, и только потом полировка. Не полируется то, что ещё может исчезнуть; правки тоже идут сверху вниз; каждый уровень заканчивается проверкой.

## Что умеет

- **Идея и жанры.** 7-факторный скоринг идей и шаблон вердикта; 17 жанров / 43 поджанра с плейбуками; атлас из 72 механик (M01-M72) и метод разбора игры из 6 вопросов; разборы ~40 топ-игр, кейсы успехов и провалов.
- **Процесс производства.** Одна главная метрика, ворота A-D с kill/pivot, журнал решений, red team, QA и релиз, план 30/60/90 дней.
- **Код и проект.** Rojo/Luau-шаблон (`--!strict`): сессионная блокировка данных, идемпотентные покупки, ремоуты с валидацией и лимитами, аналитика, PolicyService; библиотека code-only UI (окна, валюты, левое меню, офферы, тосты, полёт наград, офлайн-попап); сканер плейса для визуального аудита (`place_scan.luau`); конфиги тулчейна и CI.
- **Studio и Dashboard.** Все настройки игры, пассы, продукты, бейджи, анкета рейтинга; работа в Studio через MCP; примеры вызовов Open Cloud.
- **Монетизация.** Источники дохода, лестницы цен, офферы, ревард-реклама, налоги, политика Roblox.
- **Discovery и рост.** Алгоритм рекомендаций, чарты, поиск, реклама, запуск, дерево диагностики падения онлайна.
- **Упаковка.** Иконка, тамбнейлы, название, описание, локализация, A/B; статистика иконок по выборке из 152 игр.
- **Левел-дизайн.** Метрики (стады, прыжок, время пути, камера), спавн и первая минута, хабы, шаблоны карт по жанрам, грейбокс, свет, производительность.
- **3D, анимация, аудио.** Канон 3D-ассетов, пайплайн Blender → Studio, ИИ-3D, лицензии; анимация и моушн-канон топ-игр с таймингами; аудио-шины и канон звука.
- **ИИ-арт.** Иконки, предметы, иконка игры и тамбнейлы через Nano Banana (Gemini) или ChatGPT в браузере с единым style bible.
- **Визуальный аудит.** Каталог ошибок стиля и раскладки, scorecard, плейбук рестайла.
- **UI.** Канон UI Roblox (какие иконки, цвета и позиции ждут игроки), работа через Figma MCP, ТЗ на UI-графику.
- **Лайв-опс.** Недельный цикл, ивенты, конфиги, эксперименты, аналитика.
- **Комплаенс.** Рейтинги, Kids/Select, правила сообщества, политика монетизации, аудит перед публикацией.

## Установка

**Claude (приложение / веб).** Скачайте файл [`dist/roblox-game-dev.skill`](dist/roblox-game-dev.skill) и загрузите файл `.skill` в разделе Skills настроек Claude.

**Claude Code.** Скопируйте папку скилла:

```bash
mkdir -p ~/.claude/skills
cp -r roblox-game-dev ~/.claude/skills/
```

## Как вызывать

Скилл срабатывает на любые разговоры про Roblox. Примеры запросов:

- «Оцени идею: симулятор пекарни с кооперативным режимом. Стоит ли делать?»
- «Почему у моей игры мало игроков? QPTR 18%, отскок 70%, D1 12%.»
- «Разбери игру Grow a Garden по методу 6 вопросов и скажи, что можно перенять.»
- «Сделай игру с нуля: тайкун в жанре хоррор, я соло, бюджет ноль.»
- «Проведи аудит моей игры по ссылке и составь план доработки.»
- «Сделай монетизацию для моего симулятора питомцев: пассы, продукты, ценовая лестница.»
- «Нарисуй UI-пак для игры с яйцами и питомцами и собери его в Studio.»
- «Подготовь иконку, тамбнейлы и описание для запуска.»

## Актуальность

Данные актуальны на октябрь 2026. Roblox меняет правила ежемесячно; волатильные факты (цифры, пороги, ставки, правила) собраны в [`roblox-game-dev/references/platform-facts.md`](roblox-game-dev/references/platform-facts.md), и перед решением, зависящим от них, их нужно перепроверять по create.roblox.com/docs или DevForum.

## Ограничения

- Скилл **не прогонялся end-to-end в продакшене**: полный путь от идеи до реальной игры с живой аудиторией целиком не проверен.
- Часть цифр (выручка, пики, веса алгоритма, пороги чартов) недоступна публично и приведена как **оценка** с соответствующей пометкой. Данные трекеров по пикам до 2024 и по выручке ненадёжны.
- Статистика иконок построена на выборке из 152 игр по contact sheets (точность ±1 ступень на тонких признаках); pixel-level аудит топ-100 не делался.
- Библиотека UI в шаблоне **не тестировалась на устройстве**; перед сдачей UI нужно смотреть на размере телефона.
- Часть действий может сделать только человек (верификация аккаунта, первая публикация, API-ключ, анкета рейтинга, налоги и выплаты).
