# Starter art — Pet Legends (example set)

AI-generated (Oct 2026) with ChatGPT Images and Nano Banana (Gemini) through the user's own accounts, using the style bible and prompts in `references/builder/ai-art-generation.md` and `references/builder/ui-canon.md`, then keyed and sliced with `scripts/slice_sheet.py`. Transparent PNG, 256×256 (logo ~1000 px wide), `bg_loading.jpg` 16:9.

Use as: (1) placeholder art while prototyping any pet/collection game; (2) a STYLE REFERENCE image to upload to Nano Banana/ChatGPT so new icons match; (3) the quality bar for generated icons.
Canonical versions (per ui-canon): `ic_rebirth` red/white arrows, `ic_gem` cyan diamond, `ic_shop` red basket, `ic_codes` ticket, `shop_gift` for Daily. `ic_daily` (calendar) is the older non-canonical version kept for reference.

Files: logo, bg_loading; pets: dog (Common), cat (Uncommon), bunny (Rare), fox (Epic), dragon (Legendary), phoenix (Mythic), axolotl (Secret); eggs: basic, forest, mythic; ic_* UI icons; shop_* pass/pack icons.
Golden/Rainbow/undiscovered variants: recolour the same image (ImageColor3 / UIGradient / dark silhouette copy), don't regenerate.
Upload to Roblox via Creator Hub or the Open Cloud Assets API (see references/builder/project-setup.md); record IDs in a ui-assets.json manifest.
