# PROJECT_BRIEF: параметры конкретной игры

Шаблон скилла `roblox-game-dev`. Заполняется вместе с пользователем в начале проекта (стадия 0 пайплайна, `references/builder/pipeline.md`). Пустые поля агент заполняет сам в Фазе 0 (`references/builder/production-process.md §4`) и помечает `AI_PROPOSED` до подтверждения владельцем. Значения отсюда имеют приоритет над значениями по умолчанию. Копировать в `docs/PROJECT_BRIEF.md`.

Пометки в таблицах: `CONFIRMED` (подтвердил владелец или проверено), `AI_PROPOSED`, `HYPOTHESIS`, `BLOCKED`.

## 2. Концепция

Если концепция выбрана, заполнить. Если нет, оставить пустым: агент проводит Фазу 0 (≥8 кандидатов из ≥4 жанров, матрица под метрику, kill-критерии) и показывает топ-3.

- **Рабочее название:**
- **Официальный жанр / поджанр Roblox** (меняется не чаще раза в 3 месяца):
- **Одна фраза (hook):**
- **Ось ремикса** (сеттинг / возраст / социальный глагол / мета-слой; одна):
- **Ядро-действие** (что игрок делает каждые 5–30 с):
- **Главный вопрос игрока** («а что будет, если…?»):

- **Средняя петля** (цель на 2–5 минут):
- **Мета-прогрессия** (зачем вернуться завтра):
- **Что видно другим игрокам / на клипе:**
- **Работа на пустом сервере** (solo first):
- **Монетизация** (кратко, после ядра; без P2W и платного RNG без раскрытых шансов):
- **Запасной пивот**, если ядро не пройдёт Gate A (что переиспользуем: данные, UI, каталоги, экономика, маркетинг):
