# Survival (1 vs All · Escape · + долгий survival/crafting без поджанра)

**Назначение.** Жанровая глава для Advisor: три разных «реальности» под одной меткой Survival, как их отличать, что в каждой ломается. Рынок/CCU/циклы/плейбуки (хоррор-раннер, «N ночей», anomaly-хоррор, асимметрия, DOORS/99 Nights/MM2/Forsaken) → `advisor/genres-trends.md` §6.3, §8, §9.10–9.13; `advisor/top-games.md` §6, §9.3; возрастные/maturity-ограничения → `builder/compliance.md`; сервер/античит → `builder/code-architecture.md`.

**Актуально на:** октябрь 2026 (пакет пользователя: 02_SURVIVAL.md, сверка 21.10.2026). **Перепроверять:** список поджанров, правила maturity для хоррора, ранги жанра. Выводы пакета — типология, не измеренная статистика.

## 1. Граница и поджанры
Официально: задача игрока — выжить, убежать или победить угрожающего противника/ситуацию [ИСТОЧНИК: create.roblox.com/docs/production/publishing/experience-genres]. «Survival Craft», «Disaster Survival», «Extraction Survival» — **дизайнерские теги пакета, не поджанры**.

| Вариант | Официально? | Ядро ощущения | Пример (карточка Roblox) |
|---|---|---|---|
| 1 vs All | поджанр | охота и обман живого противника, асимметрия ролей и условий победы | Flee the Facility, Forsaken |
| Escape | поджанр | страх, считывание угрозы, «учусь на смерти», добыча и побег | DOORS, FIGURE'S LIBRARY |
| Долгий survival/crafting | нет (широкий Survival) | лагерь, ресурсы, ночь, общая история | 99 Nights in the Forest |
Break and Steal an Egg = Simulation/Tycoon с механикой Escape внутри (классифицируй по доминирующему действию). MM2 официально 1 vs All (genres-trends §6.1).

Выбор доминирующего ощущения (пакет): **погоня / исследование угроз / лагерь под осадой / асимметричная охота**. «Игра для всех» остаётся без лица.

## 2. Петля и структура сессии
- Три слоя: момент 1–5 с (услышал угрозу → спрятался/сменил маршрут); раунд 3–12 мин (вынести предмет, открыть дверь, довести группу, защитить лагерь); мета (снаряжение, способности, облики, сложность).
- Социальный крючок: спасение товарища сильнее «+100 Coins». Обратная сторона — токсичность после фейла и griefing опытными против новичков.
- **Первая цель:** пережить 30 с / принести одну вещь / добежать до безопасной точки. Не начинать с лора. Показать ценную вещь, safe zone и угрозу; первая попытка короткая и честная, но не фальшивая победа.
- **Перезапуск:** смерть → 1–3 с на понятную причину → новый шанс. Потерявший всё после 15 мин уйдёт. Ранняя ошибка = знание, а не неизбежное наказание (DOORS: учись на смертях).
- Удержание в Escape после ~10-го раза даёт только вариативность угрозы, маршрута, наград, риска; иначе погоня = «запомненный коридор». Мета не должна гарантировать побег (бесконечный speed убивает погоню).
- 1 vs All: короткие раунды, быстрый рестарт, зрительские задачи для выбывших (10 мин наблюдения после раннего поражения — главный убийца).

## 3. Сегменты (пакет)
Адреналиновый (долгая подготовка раздражает) · Тактик (изучает AI/карты, роли) · Социальный (момент в компании) · Коллекционер (шкуры/баннеры, может не любить хоррор) · Испытатель мастерства (solo/no-hit/speedrun, ценит читаемость) · Неспешный (лагерь, gathering без гонки). Возрастные доли по жанру в пакете не даны; хоррор и Mild fear/16+ trial → genres-trends §9.10, builder/compliance.md.
Роли в 1 vs All: выживший («смогу обмануть?») / охотник («смогу перехватить?», власть+ответственность) / зритель. Матч должен быть интересен в каждой роли, не 80% беспомощных целей.

## 4. Прогрессия, коллекция, статус
- Статус за мастерство: облики killer/escape, ранг роли, число rescue, метка «прошёл без урона». Prestige за реальный навык; «супер-убийца за Robux» подрывает всех.
- Escape-коллекция: редкая добыча из опасной комнаты на базе, трофеи NPC; у новичка должен быть реальный путь к первому зрелищному трофею (не недельные пробежки).
- Мета улучшает *подготовку* (вместимость, скорость, слоты), а не отменяет риск.
- Долгий survival: лучший дом, уникальный набор, число выжитых ночей, редкий NPC.

## 5. Монетизация как свойство жанра (детали → `advisor/monetization.md`)
| Модель | Что продают | Граница |
|---|---|---|
| 1 vs All PvP | анимации побед, скины, trails, loadout-пресеты, battle pass (внешний вид + умеренная валюта), приватный сервер | «купить победу» опасно: проигравший связывает бессилие с чужими тратами; ускорение *unlock'ов* допустимо |
| Escape (NPC) | скорость/выносливость/вместимость, удобство в спокойном режиме, шансы/revive, storage, скины базы, VIP | ускорять погоню можно сильнее, чем в PvP; не делать монстра нарочно невыносимым ради revive; не скрывать длительность бустеров |
| Долгий survival | профессии, удобство, boosts | зависит от глубины систем |
Забота пакета: измерять влияние покупок на проигрыши и повторные раунды; разделять skill-лидерборд и PvE-прогресс. Реклама дефицитной роли за Robux — пример из genres-trends §9.13.

## 6. Тех / mobile / античит
- **Серверная правда:** взятие предмета, location, carry capacity, сдача, награда, chase eligibility. Клиент не шлёт `I escaped with Legendary 1000`; проверять network ownership и teleport exploits. Сервисы-схема: `ThreatStateService`, `LootService`, `RoundSessionService`, профиль/экономика/receipts/analytics.
- NPC-погоня: state machine `Patrol/Alert/Chase/Return`; throttling path recalc (не сотни запросов/с); простая карта с 2–3 маршрутами; хитбокс = визуал; не «видеть сквозь стены» и не телепортироваться (иначе «игра обманывает»); safe-зона/дистанция побега; короткий cooldown после поражения.
- Mobile: single-action UI, FOV/управление, порог читаемости аудио-тэллов.
- 1 vs All: хитрег, лаг, speed/fly exploits, disconnect killer, сговор ролей; минимальная плотность игроков для честной асимметрии (при 1–2 CCU матч невозможен) → решение: одиночный loop с NPC или бот-замена (предсказуемее человека, но держит низкий онлайн).
- Безопасность: граница страха/насилия по рейтингу, предупреждение о flashing, настройка звука/мягкие эффекты.
- Долгий survival: погода, AI, инвентарь, строительство, смена суток, сохранение, кооп, экология ресурсов — стоимость поддержки часто выше, чем отдельной механики. Популярность ≠ лёгкость производства.

## 8. Сравнение моделей (типология пакета, не статистика)
| Модель | Зависимость от онлайна | Сложность | Платные преимущества |
|---|---|---|---|
| NPC chase + safe base | низкая | AI, навигация, баланс | вместимость, скорость, доход |
| Steal item from monster | низкая (NPC) | AI, сохранение лута, экономика | бег, сумка, бонус дохода |
| Pure stealth escape | низкая–средняя | слух/зрение NPC, геометрия | спорны, ломают скрытность |
| 1 vs All PvP | **высокая** | matchmaking, античит, баланс | косметика, мета |
| Infinite disaster rounds | низкая–средняя | генерация событий, репликация | бустеры, классы, визуал |
| Long survival crafting | различная | взаимозависимые системы | профессии, удобство |
Микрожанры Escape (неофициальные): chase corridor, collect & escape (+Tycoon), stealth, puzzle escape (кончается ручной контент), roguelite escape (дорогие баланс/генерация), disaster escape (без охотника, простая визуальная коммуникация).

## 9. Гибриды и эволюция
Escape+Tycoon (добыча на базе, доход) → Simulation; Escape+co-op raid (лобби → забег 1–4); 1 vs All с ростером узнаваемых персонажей; PvE/PvP-смесь с AI вместо отсутствующих ролей. Опасное: хоррор+гринд-цикл на таймерах. Рыночные волны (anomaly, «N ночей») → genres-trends §8–9.

## 10. Типичные сбои (сигнал → решение)
| Сбой | Сигнал | Решение |
|---|---|---|
| NPC слишком сильный | много фейлов первой попытки (иллюстративно ~70%; не норма) | упростить первую комнату, дать укрытие |
| NPC слишком слабый | мало near misses | несколько вариантов AI/маршрутов |
| Пустой сервер | первый игрок не войдёт в матч | одиночный loop с NPC |
| Роль не достаётся | уходят из лобби | короче раунды, спектатор-активность |
| Pay-to-win | жалобы free-игроков | разделить leaderboard и PvE-мету |
| Гринд на таймере | повторяют, но D1 низкий | новые сценарии, а не ожидание |
| Баг сохранения | пропали трофеи | серверные транзакции, retries |
| Перебор хоррора | отзывы, maturity-ограничения | мягкие эффекты, звук |

## 11. «Как сделать хит соло» (чек-лист)
1. Выбери одно ощущение (погоня / исследование / лагерь / охота) и поджанр; Escape-NPC дешевле 1 vs All в старте.
2. Одна локация, один враг, 2–3 маршрута, state machine — proof-of-fun до мультиплеерных ролей (позиция «разработчика» пакета).
3. Первые 30 с — цель, safe zone, угроза, без текста; смерть → рестарт ≤3 с.
4. Витрина добычи на базе (социальный крючок и клип «вырвал яйцо → тревога → safe zone»).
5. Серверный лут/carry/сдача; профиль с трофеями; идемпотентные покупки.
6. Монетизация: вместимость/скорость/удобство/косметика; никакой «непобедимой» роли за Robux.
7. Вариативность после 10-го прогона: пул угроз, события, этажи/сезоны (genres-trends §9.10).
8. Если PvP: план на малый онлайн (боты/NPC), метрика времени ожидания лобби.
9. Проверь maturity-рейтинг и возраст до дизайна страха.
10. Для коротких клипов (discovery): действие понятно без UI.

## 12. Открытые вопросы (из пакета)
Доли возрастных сегментов по предпочтению (хоррор/погоня/строительство/PvP); влияние сложности NPC на добровольный повтор; какие события дают повторные групповые матчи; соотношение косметики/ускорения/revive/контента; как баланс и цены меняются с ростом живой аудитории. Причинная связь «монстр / пассивный доход / цена revive → успех» без внутренних данных недоказуема.
