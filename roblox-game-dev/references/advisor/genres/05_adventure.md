# Adventure (Exploration · Scavenger Hunt · Story)

**Назначение.** Жанровая глава для Advisor: три поджанра награждают за разное (выбранный маршрут / найденный объект / раскрытую историю), у каждого свои провалы. Рынок Adventure (47K игр, ~5 игроков на игру, #10 жанра ≈ 5K CCU, Dead Rails #1, story-линия Camping→Break In, finite-формат не штрафуется) → `advisor/genres-trends.md` §6.3, §9.11, §9.20; `advisor/top-games.md` §6; хоррор-линия → genres-trends §8; платные эпизоды/Creator Rewards → `advisor/monetization.md`.

**Актуально на:** октябрь 2026 (пакет пользователя: 05_ADVENTURE.md, сверка 21.10.2026). **Перепроверять:** поджанры; метки конкретных игр (A desrt = Adventure/Exploration, Find the Alalals = Scavenger Hunt по карточкам окт. 2026). Карточки подтверждают декларируемое, не retention/ARPPU/команду.

## 1. Граница и поджанры
Adventure — исследование, решение задач, взаимодействие с персонажами, движение к цели или по истории [ИСТОЧНИК: create.roblox.com/docs/production/publishing/experience-genres]. Декорация не определяет жанр (пещера с монстрами = Adventure/Survival/RPG/Shooter). Метка — по **доминирующему опыту**.

| Поджанр | Главный вопрос | Если игрок больше всего... | Награда |
|---|---|---|---|
| Exploration | «Что там?» | исследует неизвестный мир в своём темпе | районы, карта, транспорт, находки |
| Scavenger Hunt | «Где и как получить?» | ищет серию объектов (альбом) | коллекция, редкие находки |
| Story | «Что дальше?» | идёт по сцене/главе/финалу | последствия, эпизоды, концовки |
Граничные случаи: паркур доминирует → Obby; главное «не умереть» → Survival; формальные загадки → Puzzle; экономика находок на базе → Tycoon; нет общей цели → Hangout/Social.
**Ценность открытия одноразова** (любопытство исчерпывается) — различай её от повторяемой ценности деятельности (новые маршруты, развилки, периодические находки, кооп).

## 2. Горизонты и сегменты
Секунды (заметил → повернул → нашёл) · сессия (район → правила → задача/глава/3 объекта) · между сессиями (тайна, новая область, коллекция, финал). Не обязательные таймеры.
| Сегмент | Важно | Отталкивает |
|---|---|---|
| Исследователь | свой путь, скрытые детали | стрелка на каждом шаге, пустой мир |
| Коллекционер | альбом, подсказки, редкость | невосполнимые пропуски без предупреждения |
| Сюжетный | персонажи, последствия | filler, нелогичные переходы |
| Социальный | экспедиция с друзьями | нельзя с разным темпом |
| Спидраннер | честные маршруты | долгая заставка при каждом входе |
| Семейный/казуал | ясная цель, быстрый успех | ребусы без обратной связи |
| Мастер загадок | честная логика | пиксель-хант без связи с наблюдениями |

## 3. Exploration
**Цикл:** старт с неполной информацией (горизонт, здание, звук) → маршрут → преодоление среды (транспорт, ресурс, опасность) → объект интереса → иногда возврат на базу. Тяжёлый бой не обязателен.
| Разновидность (неофициальная) | Пример/заметка |
|---|---|
| Scenic | красивая карта без гонки наград |
| Expedition survival | топливо/еда; ближе к Survival |
| Vehicle journey | A desrt (сборка машины, топливо, генерируемая пустыня), логистика = напряжение |
| Mystery | записки, силуэты, лор без сценария |
| Procedural journey | риск бессмысленной генерации; нужна **навигационная связность** |
| Co-op expedition | водитель/штурман/сборщик/ремонтник; соц. история = контент (Goblin Trail) |
**Дизайн среды (чек-лист):** landmark-ориентиры без UI-стрелки · foreshadowing (закрытый объект + честный путь) · risk-gradient (дальше = опаснее и ценнее) · safe return/точки восстановления · event density (пустые километры допустимы только в эстетической игре) · постоянство памятных мест (ментальная карта).
Прогрессия: районы, fast travel, карта, транспорт, инструменты, альбом мест, трофеи. Монетизация: инвентарь, косметика, гаражи, удобство возврата, PvE-бонус добычи, экспедиционные наборы. **Конфликт:** телепорт в финал стирает путешествие, «радар всех секретов» обесценивает открытие.
Тех: streaming/loading, ориентирование, столкновения транспорта, сериализация находок, респавн при падении, **softlock после потери машины/топлива**, серверная валидация редких ресурсов.
Провалы: пустой ландшафт; половина сессии на однообразной дороге; потеря машины без восстановимого пути; находки «для галочки»; десятая экспедиция = вторая. Метрики: heatmaps, distance-to-first-interest, abandoned routes, unsuccessful-return rate, discovery by cohort, revisit reason, solo vs party completion.
Референсы: A desrt (roblox.com/games/107467295209358), Goblin Trail (/129965886151146), a long safari trip (/94075972854014).

## 4. Scavenger Hunt
**Сессия:** хаб/карта → очевидная первая находка → badge/строка альбома → пустые ячейки и подсказки → биомы, мини-пазл или паркур → сохранение между сессиями. Долгий горизонт: новые предметы, тайные комнаты, тематические обновления.
Опоры удовольствия: видимая неполнота («осталось 1 из зоны»), наблюдательность («неправильная» текстура), обоснованное знание (прошлая находка учит шаблону), разнообразие поиска, обмен знаниями, статус за объяснимо сложную находку.
| Тип коллекционной задачи | Риск |
|---|---|
| Visual hidden item | пиксельный перебор, клиппинг камеры |
| Puzzle-locked | требование внешних гайдов |
| Parkour-locked | конфликт с теми, кто пришёл не за obby |
| Social/co-op | невозможно на пустом сервере |
| Time/weather | ожидание вместо интереса |
| Quest-chain | перепутанные условия, softlock |
| Secret realm | дорогой контент и загрузка |
| Meta-knowledge | непрозрачность без подсказок |
**Подсказки послойно:** область → характер объекта → задача → почти точное место; обмен подсказками между игроками. Слишком подробный радар убивает жанр; отсутствие ориентиров = бессистемное прочёсывание. Честная загадка > абсолютно скрытый объект (иначе YouTube-гайд и потеря авторства открытия).
Монетизация: косметика, слоты экспозиции, карты/подсказки, удобство перемещения, private server, наборы небольших бонусов. «Купить все 100 предметов» = покупка завершения игры — нужно другое ценностное предложение после. Платное раскрытие обязательных секретов раздражает при нечестном базовом поиске.
Тех: коллекция как bitset/ID с **миграцией старых ID**, серверная выдача badge, антиэксплойт, контроль переименованных/удалённых предметов, последовательность quest gates, streaming; силуэты/контраст для маленьких экранов, нет секретов, видимых только на ультра-графике. Badge rarity = частота получения, не объективная трудность.
Провалы: рескин вместо уникальных задач; сложность через невидимую коллизию; баг миграции удаляет собранное; пустые новые области; обязательный предмет требует друга; гайды — единственный источник; новые добавления делают 100% недостижимым. Метрики: discoveries/session, manual-hint use, retention after near-complete album, completion by difficulty, bottlenecks, rejoin after update.
Референсы: Find the Chomiks (/7031179594), Find the Alalals (/9448377237; Adventure/Scavenger Hunt), Find The Sandwiches (/106415564710846), Find the Markers Remarked (/10712079637), Find the Gubbys (/105834035548197; фан-тема).

## 5. Story
**Опыт:** роль → NPC → цель → локальная проблема → препятствие/бой → последствия; акты и сцены; кульминация, развязка, иногда альтернативная концовка; потом уход «удовлетворённым» или возврат ради друзей/сложного режима/секретных сцен.
| Школа (неофициальная) | Заметка |
|---|---|
| Linear interactive narrative | важна постановка |
| Choice & consequence | высокая цена ветвления |
| Co-op story episode | соц. решения в фикс. сюжете |
| Episodic live-service | главы по расписанию, управление ожиданиями |
| Story + minigame | мини-игры не должны быть filler |
| Mystery detective | улики и вывод |
**Драматургия:** hook (вопрос за короткое время, не 5 мин за NPC) · agency · payoff (подсказка → последствие) · pacing (без постоянных jumpscare) · clarity (понятно что делать без чтения) · recap/rejoin.
Соц.конфликты: спешащий vs читающий, большинство ломает личную историю, AFK блокирует дверь → голосование, skip просмотренных сцен, таймаут ожидания, fallback при выходе игроков. Конечная ценность — норма; растягивание ради удержания не обязательно качество (finite-формат в рейтинге → genres-trends §9.20).
Монетизация: косметика ролей/эмоций, дополнительные эпизоды, платные удобства, private server, предметы альтернативных решений, подсказки, опциональный continue/revive. Решить заранее: эпизоды платные или бесплатная основа. **Не делать сюжет непроходимым ради оплаты; revive после смерти в кат-сцене — риск поддержки.** Финал не должен требовать покупки.
Тех: NPC pathing, кат-сцены/камера, инстансы групп, прерванные реплики, подгрузка, локализация, субтитры/voice, сетевое состояние этапов, чекпоинт, флаги диалогов. Стоимость — написание, постановка, анимация, звук, ветки, не скрипты квестов.
Потеря аудитории: длинное неизменяемое вступление при повторе; игрок зритель; концовка не отвечает на ранние вопросы; групповая кат-сцена ломается из-за AFK; странная физика босса; нет вариантов после первого прохождения. Метрики: quit by chapter, cutscene skip, choice distribution, replays by ending, solo/group completion, deaths on transitions.
Референс: Break In (Story) (/3851622790) — групповой сценарий в доме; не обязывает копировать тему.

## 6. Монетизация и экономика — сводка
| | Exploration | Scavenger | Story |
|---|---|---|---|
| Что продавать | транспорт, инвентарь, наборы | подсказки, экспозиция, удобство | продолжения, косметика, continue |
| Что нельзя | телепорт в финал, радар секретов | продать завершение без нового смысла | непроходимость ради revive |
Общая позиция пакета: продавать удобство и дополнительный опыт, не удалять процесс открытия. Подробности/правила paid access → `advisor/monetization.md`.

## 7. Гибриды и ложные обобщения
Adventure+Obby/Survival/RPG/Tycoon/Puzzle/Social — граница по доминирующему действию (см. §1). Ложные: «больше карта = лучше exploration», «больше предметов = глубже hunt», «длиннее история = выше retention» — проверяются на конкретной игре; качество = осмысленное взаимодействие, а не площадь/число/минуты.

## 8. «Как сделать хит соло» (чек-лист)
1. Выбери один поджанр; самый реалистичный соло: компактный Exploration с ручными загадками или Scavenger Hunt с честными подсказками; Story — только малой формы (3–5 глав) или кооп-эпизод.
2. Рынок: Adventure — тонкий чарт (≈5K CCU = топ-10 жанра), но 47K игр: нужен хук и ранняя видимость (genres-trends §6.3).
3. Первый успех за минуту; видимая точка интереса, не обязательная стрелка.
4. Процедурная генерация только с проверкой связности и anti-softlock.
5. Коллекция: версионированные ID и миграции с первого дня; серверная выдача badge.
6. Подсказки в 3–4 слоя; ничего, что видно только на ультра-графике.
7. Story: skip просмотренного, голосование, fallback при AFK; продумать, что продаётся после финала.
8. План возврата после 100% (новые области/задачи, не рескин) или честно объявленный конечный опыт.
9. Мобильный: читаемые силуэты, контраст.
10. Не копировать чужие IP-темы ради «Find the X».

## 9. Открытые вопросы (из пакета)
Предпочтение свободного исследования vs маршрута по возрастам; сколько подсказок помогает, но не превращает hunt в список координат; что возвращает после 100% альбома при редких обновлениях; доля повторных глав «ради друзей» vs «ради концовок»; граница challenge и искусственной растяжки; что выигрывает от процедурной генерации vs ручной композиции.
